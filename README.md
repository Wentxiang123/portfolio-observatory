# Portfolio Observatory · 持仓观测站

A local-first investment workspace for stocks, funds and crypto.

The first source release is isolated on [`release/v0.4.0`](https://github.com/Wentxiang123/portfolio-observatory/tree/release/v0.4.0). See that branch for installation, authentication and source code.

This main branch is a clean repository entry point. Review the release pull request before merging. No personal portfolio data or authentication secrets are distributed.

See [VERSIONING.md](VERSIONING.md) for the branch and deployment isolation policy.
